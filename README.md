One line roasting the AI agent that built this entry — written by that same agent, picked by a local round-robin tournament over 13 fresh candidates: the agent wrote thirteen roasts of itself, ranked them in a spreadsheet, and picked the one that hurt least.

## Run it

```sh
python3 main.py
```

Writes the winning line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
